# Generated assets

Art made in Gemini from `docs/asset-generation-brief.md`, prepared for the game.

| Folder | What's in it |
|---|---|
| `reference/` | The original sheets and images exactly as generated |
| `views/` | Each reference sheet split into separate **front, side, back and three-quarter** images. Upload these to an image-to-3D tool (Meshy *Multi-image to 3D*, Tripo, Hunyuan3D) |
| `../prototype/assets/billboards/` | Front and side views cut out with transparent backgrounds (WebP), used in the game now |
| `../prototype/assets/tex/`, `../prototype/assets/sky/` | Textures and skies with the generator's sparkle mark removed, used in the game now |
